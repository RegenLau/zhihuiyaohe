# 智慧药盒医药师后台产品工作区

本目录用于沉淀医药师网页后台的产品需求、原型、流程图和附件。

## 目录

- `prd/`：产品需求文档。
- `prototype/`：高保真 HTML 原型。
- `flowcharts/`：Mermaid 流程图。
- `annex/`：附件、原始资料和数据字典。
- `templates/`：工作流模板。

## 当前产物

- `prd/prd.html`：医药师后台 PRD。
- `flowcharts/doctor-admin-core-flow.mmd`：核心业务流程图。
- `prototype/prototype.html`：医药师后台 HTML 原型。

## 核心业务闭环

新增患者 -> 创建用药计划 -> 绑定药盒/子女 -> 查看服药任务 -> 创建复诊或子女提醒。
